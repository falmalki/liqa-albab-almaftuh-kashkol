# كشكول لقاء الباب المفتوح

كشكول رقمي للقراءة والرفقة مع كتاب **لقاء الباب المفتوح** للشيخ محمد بن صالح العثيمين رحمه الله (المصدر: Shamela 7687 / turath.io).

التطبيق **ملف واحد** `index.html` فيه كل التنسيق والبرمجة والبيانات، بلا خادم ولا مكتبات ولا خطوات بناء. يعمل دون اتصال بعد فتحه مرة، ويُضاف إلى الشاشة الرئيسية على iPhone.

## ما يحتويه

- **القراءة**: ٦٤٦٠ مسألة موزّعة على ٢٣٥ لقاءً، و٣١٦٦ صفحة مدمجة، و١٥ موضوعاً، مع رقم موقع ثابت لكل مسألة.
- **مسائل اليوم**: ثلاث مسائل من مختاراتك أو محفوظك، مع إمكانية إخفاء الجواب للاستظهار، وستة مسارات قراءة غير اختبارية.
- **مختاراتي**: التظليلات، المختارات، قيد الحفظ، المحفوظة، والفوائد — كلها بوصلات تعيدك إلى الموضع نفسه.
- **بحث**: يتجاوز الحركات والهمزات، ويجمع بين الكلمة والوسوم، مع فهرس اللقاءات، والعودة إلى موضع القراءة الأصلي.
- **أدوات القارئ**: ثلاث حالات للحفظ، فائدة لكل بطاقة، تصحيح النص مع شارة «معدَّل»، تظليل بملاحظة، تركيز، حفظ مكان القراءة، وآخر خمسة مواضع.
- **التصدير**: JSON احتياطي، Markdown، Anki TSV (تصدير فقط — لا اختبارات داخل التطبيق)، وEPUB يُنشأ داخل المتصفح.

> ملاحظة منهجية: النص محفوظ حرفياً من المصدر. الفوائد والتعديلات والتظليل تُحفظ منفصلة في `localStorage` ولا تغير النص الأصلي. لا توجد اختبارات أو درجات داخل الكشكول.

## الاستخدام على iPhone

1. ارفع `index.html` إلى مستودع GitHub وفعّل Pages، أو افتحه من ملف محلي/خدمة استضافة ثابتة.
2. افتح الرابط في **Safari** (ليس في متصفح داخل تطبيق آخر).
3. اضغط زر **المشاركة** ⬆️ ثم **إضافة إلى الشاشة الرئيسية**.
4. افتح الأيقونة من الشاشة الرئيسية؛ سيعمل التطبيق بلا شريط Safari وبصورة standalone.

## النسخ الاحتياطي

كل تقدّمك محفوظ في `localStorage` تحت المفتاح `liqa-albab-almaftuh-kashkol-v2` على ذلك الجهاز/المتصفح فقط. لا يُرفع إلى أي خادم. استخدم **الإعدادات ← تصدير JSON** بشكل دوري، واحتفظ بالملف. عند الاستيراد يُرفض أي ملف من كتاب آخر، ويمكن دمج الفوائد وحدها من نسخة أخرى.

## النشر على GitHub Pages

أداة `gh` غير مثبتة على الجهاز الذي بُني فيه الكشكول، لذا إليك الأوامر اليدوية:

```bash
cd site
git init
git add index.html README.md
git commit -m "كشكول لقاء الباب المفتوح"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/liqa-albab-almaftuh-kashkol.git
git push -u origin main
```

ثم في GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / root**، واحفظ. بعد دقائق سيكون الرابط:
`https://<YOUR_USERNAME>.github.io/liqa-albab-almaftuh-kashkol/`

إذا فضّلت Vercel: استورد المستودع، واترك Framework على **Other**، وأمر البناء فارغاً، ومجلد الإخراج هو الجذر.
